# mcquillen ┊ interactive

McQuillen Interactive is an independent software studio run by
[Daniel McQuillen](https://github.com/danielmcquillen), building web and
desktop applications with an emphasis on simple, clean user interfaces —
with a focus on projects in building science and e-learning.

More at [mcquilleninteractive.com](https://www.mcquilleninteractive.com).

## What's here

This organization hosts the public repositories for McQuillen Interactive
products and projects:

- **[Validibot](https://validibot.com)** — gives organizations a collaborative
  way to create and monitor automated validation workflows for their users.
  Public Validibot repositories are moving to this organization.
- **PureLMS** — a learning management system, coming to this organization
  later.

Personal and experimental projects remain on
[@danielmcquillen](https://github.com/danielmcquillen).
